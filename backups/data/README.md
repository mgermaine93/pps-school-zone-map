# Data

This is the important data directory...do not mess with it!

* `addresses_slim.json` is what the app ultimately draws from.  This large file contains all of the valid non-duplicated Pittsburgh addresses and their respectives schools.
* `cleaned_new_pps_schools.json` is basically `addresses_slim.json`, but a more browser-optimized version.
* `schools.json` includes school data.
* `pittsburgh_addresses.json` comes from OpenAddresses.io.
