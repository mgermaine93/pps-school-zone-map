# data

Contains the data files served by the web app. All files in this directory are generated by the monthly refresh pipeline (`main.py`) and should not be edited by hand.

## Files

| File | Generated by | Description |
|---|---|---|
| `schools.json` | `pipeline/refresh_schools.py` | Current list of PPS schools with name, type, address, phone, hours, and coordinates. Loaded by `index.js` to populate school detail popups and the school-location pin layer. |
| `addresses_slim.json` | `pipeline/scraper-v2.py` | Compact JSON mapping every Pittsburgh address to its assigned schools. Intermediate format consumed by `build_binary.py`. |
| `addresses.bin` | `pipeline/build_binary.py` | Binary-encoded version of `addresses_slim.json` in the custom PPSb format. Roughly 3× smaller than the slim JSON and parsed near-instantly by the browser's `DataView` API. This is the primary data file loaded by `index.js`. |
| `addresses_full.json` | `pipeline/scraper-v2.py` | Full intermediate output from the scraper containing all raw API fields. Only `addresses_slim.json` is consumed downstream; this file exists for debugging and is excluded from version control. |
