# img

Contains the SVG icon files used by the map.

## Files

| File | Used for |
|---|---|
| `favicon.svg` | Browser tab icon. |
| `favicon-elementary.svg` | Map pin for elementary schools. |
| `favicon-k8.svg` | Map pin for PreK–8 schools. |
| `favicon-middle.svg` | Map pin for middle schools. |
| `favicon-highschool.svg` | Map pin for high schools. |
| `favicon-online.svg` | Map pin for online schools. |
| `favicon-house.svg` | Address marker placed when a user searches for a specific address. |

School pins are placed on the map when a user selects an address from the search bar or filters by school. Icon files are referenced in `index.js`.
